Support Center Guide

Date: February 11, 2026

For: Internal Users & Administrators

1. Introduction to Support Center

The Support Center is your centralized hub for resolving issues, tracking requests, and getting instant answers. Integrated directly into the BPP settings, it allows you to:

  • Log bugs and feature requests directly to Jira.
  • Chat with an AI Assistant for troubleshooting.
  • Track the status of your submitted tickets.
Accessing Support: Navigate to Settings via the sidebar, then select the Support tab (look for the ? icon).

2. Logging a New Issue

If you encounter a bug or need access to a specific feature, use the "Log Issue" tab.

1
Select Category: Choose the type of issue (Bug, Access, Billing, etc.) to route your ticket correctly.
2
Set Priority: Mark urgent issues as High/Critical. Please reserve Critical for system outages only.
3
Describe the Issue: Provide a clear title and detailed description.
4
Attachments: You can attach screenshots or error logs if available.

Figure 1: The 'Log Issue' submission form

3. Tracking Ticket Status

View all your submitted requests in the "My Tickets" tab. This view provides real-time updates from the Jira system.

1
Status Badges:
  • Open: Ticket received, waiting for assignment.
  • In Progress: Team is actively working on it.
  • Resolved: Issue fixed or request completed.

Figure 2: Viewing ticket history and status

4. Using the AI Assistant

For immediate help, ask the AI Assistant. It is trained on the BPP documentation and can answer questions about promotion rules, billing, and common errors.

Tip: You can ask questions like "How do I create a deposit bonus?" or "Why can't I login?"

Figure 3: Interactive AI Support Chat

5. Configuration (Admin Only)

Administrators can configure how the support system connects to external tools.

  • Jira Integration: Automatically creates tickets in a specified Jira Project.
  • Email Routing: Sends support requests to a shared inbox (e.g., support@betika.com) if Jira is down or not used.

Figure 4: Admin configuration for support integrations

Note: Changing the Jira Project Key will affect where new tickets are created. Ensure the service account has write permissions to the new project.
