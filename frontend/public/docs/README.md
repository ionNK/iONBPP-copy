## 🖨️ How to Generate PDF

### Automated Generation (Recommended)

The system now includes an automated script to generate the PDF with all images and styling correctly preserved.

1. **Run the generation script:**
   ```bash
   node scripts/generate-pdf.js
   ```

2. **Output Location:**
   The PDF will be generated at: `public/docs/Betika-Promotions-Platform_User_Manual_v1.0.pdf`

3. **Verify:**
   Open the file to ensure all images and styles are correct.

### Manual Method (Fallback)

1. Open `Betika-Promotions-Platform_User_Manual_v1.0.html` in your browser
2. Use the browser's "Print" function (`Ctrl+P` / `Cmd+P`)
3. Select "Save as PDF"
4. Ensure "Background graphics" is enabled to preserve colors
